# 単語追加画面 振る舞い仕様書

## 1. 機能概要

表と裏の2枚のカードに入力して、フォルダに単語を追加する画面（`/word-create/<フォルダの id>`）。単語一覧画面の「単語を追加」から開く。
表を「保存」で確定してから、裏を入力して「保存」すると単語を登録し、単語一覧画面に戻る。

対象の概要設計書は `docs/high_level_design/presentation/word/high_word_create_page.md`（根拠欄の `概要 §<見出し>`）。
単語の保存の結果は `docs/detailed_design/online_offline/word_repository.md`（WRD-C）で定める。

ログイン中のユーザーは id が `u1` のユーザー、フォルダは id が `F`、名前が「F」のフォルダとする。
特に書かない限り、フォルダ「F」には単語「A」（表 `apple`・裏 `りんご`）が1件あり、単語一覧画面（`/folder/F`）で「単語を追加」をタップしてこの画面を開いたものとする。
条件の「表を確定した」は、表のカードを開いて入力し、「保存」をタップしてカードが元の大きさに戻った状態を指す。

## 2. データ定義

### 2.1 入力

| 項目 | 型 | 説明 |
|------|----|------|
| 表 | String | 単語。前後の空白を除いて登録する |
| 裏 | String | 意味。前後の空白を除いて登録する |
| 確定した表 | String? | 表の「保存」で確定した、前後の空白を除いた表。確定前は null |

## 7. 対象外

- **`NetworkFailure` / `AuthFailure`**: 単語の登録は端末内のデータベースだけを使い、リモートと通信しないため発生しない（WRD 7章）
- **「1文字以上入力してください！」の表示**: この画面では、空の間は「保存」を表示しないため、表示されることがない（表示は単語編集画面の WED で定める）
- **「×」「保存」「ラベル」の位置（右上・右下・左上）と「保存」のチェックのアイコン**: Widget テストで配置・アイコンの絵柄を観測しないため、項目を作らない（表示の有無は WCR-D01〜D03 で確かめる）
- **入力欄のキーボードの表示**: Widget テストでキーボードを観測しないため、入力欄にフォーカスが当たること（WCR-D02, F06）で確かめる
- **500文字の数え方**: Flutter の入力欄の既定（見た目の1文字＝1文字。絵文字・改行も1文字）に従う。数え方そのものはテストしない
- **カードの広がるアニメーション・角の丸み・影**: Widget テストで観測しないため、項目を作らない（観測するのは、入力欄・「×」・「保存」・もう一方のカードの表示の有無）
