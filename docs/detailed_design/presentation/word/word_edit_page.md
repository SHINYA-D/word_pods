# 単語編集画面 振る舞い仕様書

## 1. 機能概要

登録済みの単語の表と裏を、カードを開いてその場で書き換えて保存する画面（`/word-edit/<フォルダの id>`）。単語一覧画面で単語の行、またはメニューの「編集」から開く。保存してもこの画面に残る。

対象の概要設計書は `docs/high_level_design/presentation/word/high_word_edit_page.md`（根拠欄の `概要 §<見出し>`）。
単語の変更の結果は `docs/detailed_design/online_offline/word_repository.md`（WRD-U）で定める。

ログイン中のユーザーは id が `u1` のユーザー、フォルダは id が `F` のフォルダとする。
特に書かない限り、フォルダ「F」には単語「A」（表 `apple`・裏 `りんご`）と単語「B」（表 `banana`・裏 `バナナ`）がこの順にあり、単語一覧画面で `apple` の行をタップしてこの画面を開いたものとする。
条件の「最後に保存した内容」は、開いた時点では単語「A」の表・裏、保存に成功した後はそのとき保存した表・裏を指す。

## 2. データ定義

### 2.1 入力

| 項目 | 型 | 説明 |
|------|----|------|
| 表 | String | 単語。前後の空白を除いて保存する |
| 裏 | String | 意味。前後の空白を除いて保存する |

## 7. 対象外

- **`NetworkFailure` / `AuthFailure`**: 単語の変更は端末内のデータベースだけを使い、リモートと通信しないため発生しない（WRD 7章）
- **変更前と完全に同じ内容での保存**: 最後に保存した内容と完全に同じ間は「保存」を表示しない（WED-D05）ため、操作できない（前後の空白だけが違う場合は WED-U24）
- **入力欄のキーボードの表示**: Widget テストでキーボードを観測しないため、入力欄にフォーカスが当たること（WED-D02, D03）で確かめる
- **単語の削除**: この画面には無い（単語一覧画面の WLS で定める）
- **500文字の数え方**: 単語追加画面（WCR 7章）と同じ
- **カードの広がるアニメーション・角の丸み・影、「1文字以上入力してください！」の色**: Widget テストで観測しないため、項目を作らない
