# 単語一覧画面 振る舞い仕様書

## 1. 機能概要

フォルダの単語を一覧で表示し、検索・削除と、単語追加画面・単語編集画面・テスト設定画面への移動を行う画面（`/folder/<フォルダの id>`）。ホーム画面でフォルダの行を押下して開く。

対象の概要設計書は `docs/high_level_design/presentation/word/high_word_list_page.md`（根拠欄の `概要 §<見出し>`）。
単語の保存・削除の結果は `docs/detailed_design/online_offline/word_repository.md`（WRD）で定める。
単語の追加・変更は、この画面と同じ ViewModel（`WordListViewModel`）を使い、それぞれ `word_create_page.md`（WCR）・`word_edit_page.md`（WED）で定める。

ログイン中のユーザーは id が `u1` のユーザー、開いたフォルダは id が `F`、名前が「F」のフォルダとする。
単語「A」は表 `apple`・裏 `りんご`、単語「B」は表 `banana`・裏 `バナナ` で、「A」のほうが作成日時が古いものとする（`getWords` は作成日時の古い順に返す）。

## 2. データ定義

### 2.1 Word

| 項目 | 型 | 説明 |
|------|----|------|
| id | String | 単語の id |
| front | String | 表（単語） |
| back | String | 裏（意味） |
| createdAt | DateTime | 作成日時 |
| updatedAt | DateTime | 更新日時 |

### 2.2 WordListViewModel の状態

| 項目 | 型 | 説明 |
|------|----|------|
| （状態そのもの） | AsyncValue<List<Word>> | フォルダの単語の一覧。フォルダの id ごとに持つ |

### 2.3 入力ルール

該当なし（検索の入力は、どんな文字列でも受け付ける。絞り込みの規則は 3.2 で定める）。

## 7. 対象外

- **`NetworkFailure` / `AuthFailure`（全操作）**: 単語の読み取り・削除は端末内のデータベースだけを使い、リモートと通信しないため発生しない（WRD 7章）
- **読み込みの `NotFoundFailure`**: フォルダが削除済み・存在しない場合も空の一覧を返す（WRD-R06・R07）ため発生しない
- **全フォルダ横断の検索**（`requirements.md` §6-1-1）: この画面には無い（概要設計書にも無い）
- **他のユーザーの単語を表示しないこと（原則-9）**: Repository の契約（WRD-R03）で検証する。画面では userId `u1` で呼ぶこと（WLS-V02）だけを確かめる
- **ボトムナビゲーションバー**: SHL で定める
- **「削除」の文字・ボタンの色、アイコンの絵柄**: Widget テストで観測しないため、項目を作らない
