# パスワード再設定画面 振る舞い仕様書

## 1. 機能概要

入力したメールアドレスへ、パスワード再設定用のリンクを送る画面（`/password-reset`）。ログイン画面の「パスワードを忘れた方」から開き、送信に成功するとログイン画面に戻る。

対象の概要設計書は `docs/high_level_design/presentation/auth/password_reset/high_password_reset_page.md`（根拠欄の `概要 §<見出し>`）。

条件の「送信が成功した」は、`sendPasswordResetEmail` が `Right(unit)` を返したことを指す。
特に書かない限り、ログイン画面（`/login`）から「パスワードを忘れた方」をタップしてこの画面を開いたものとする。

## 7. 対象外

- **`NotFoundFailure` / `RecentLoginRequiredFailure` / `TooManyRequestsFailure`（画面）**: `AuthRepository.sendPasswordResetEmail` はこれらを返さないため、画面の行を作らない。ViewModel の文言の対応は PWR-V07〜V09 で定める
- **通信エラーダイアログと強制ログアウト（原則-11）**: ログイン前の画面なので当てはめない（概要 §送信に失敗したとき）
- **AuthRepository のエラーの変換**: 認証の Repository の仕様書が無いため、この仕様書では扱わない
- **入力のチェックの文言の位置（入力欄の下）・赤字**: Widget テストで位置と色を観測しないため、文言が表示されること（PWR-S01）だけを確かめる
- **ログイン中のパスワードの変更**: ログアウトしてからこの画面で行う（`high_account_page.md` §パスワード変更、ACI-P）。ログイン中にこの画面を開く経路はない
- **再設定メールの中身・リンクの先の画面**: Firebase Authentication が提供するもので、アプリの動作ではない
