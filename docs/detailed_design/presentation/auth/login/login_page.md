# ログイン画面 振る舞い仕様書

## 1. 機能概要

メールアドレスとパスワードでログインする画面（`/login`）。ログインしていない状態での起動・ログアウト・退会の後に表示する。
「パスワードを忘れた方」でパスワード再設定画面（`/password-reset`）へ、「新規登録」で新規登録画面（`/sign-up`）へ移動する。

対象の概要設計書は `docs/high_level_design/presentation/auth/login/high_login_page.md`（根拠欄の `概要 §<見出し>`）。
次はこの仕様書では扱わず、それぞれの仕様書で定める。

| 内容 | 仕様書 |
|-----|-------|
| ログインの UseCase（初回の同期・同期の失敗の扱い） | `docs/detailed_design/online_offline/online_offline.md`（SYN-L01〜L03） |
| ログイン後の振り分け（未確認ユーザーの `/verify-email`） | `docs/detailed_design/email_verification/email_verification.md`（EMV-G） |
| 退会の完了ダイアログ | `docs/detailed_design/presentation/settings/settings_page.md`（ACD） |

条件の「正しい入力」は、「メールアドレス」に `a@example.com`、「パスワード」に `password1` を入力した状態を指す。
「ログインが成功した」は、`signInWithEmail` が `Right(AppUser)`（メールアドレス確認済み）を返し、初回の同期も終わったことを指す。

## 7. 対象外

- **Google でログイン**（`signInWithGoogle`）: ボタンを表示していないため、画面からは操作できない（概要 §画面構成）。Sign in with Apple と一緒に戻すときに仕様を追加する
- **`NotFoundFailure` / `RecentLoginRequiredFailure` / `TooManyRequestsFailure`（画面）**: `AuthRepository.signInWithEmail` はこれらを返さない（Firebase のエラーを `NetworkFailure`・`AuthFailure`・`UnknownFailure` にだけ変換する）ため、画面の行を作らない。ViewModel の文言の対応は LGN-V07〜V09 で定める
- **通信エラーダイアログと強制ログアウト（原則-11）**: ログイン前の画面なので当てはめない（概要 §ログインに失敗したとき）
- **退会の完了ダイアログ**: ACD で定める
- **ログイン後の未確認ユーザーの振り分け**: EMV-G で定める
- **AuthRepository のエラーの変換**: 認証の Repository の仕様書が無いため、この仕様書では扱わない
- **ブランドの配色・ステータスバーの文字色・ロゴの大きさ・文字の太さ・リンクの下線**: Widget テストで色・大きさ・装飾を観測しないため、項目を作らない
- **キーボードを表示しているときのスクロール**: Widget テストでキーボードの表示を再現しないため、小さい端末でスクロールできること（LGN-D05）で確かめる
- **入力のチェックの文言の位置（入力欄の下）・赤字**: Widget テストで位置と色を観測しないため、文言が表示されること（LGN-L01〜L03）だけを確かめる
- **ログイン画面での戻る操作**: 概要設計書に定めがなく、OS の既定の動作（アプリを閉じる）に任せる
- **ログアウト・退会・強制ログアウトの後にこの画面へ移動すること**: 移動する側の仕様書（APS-O02・ACD）で定める
