# 単語テスト（テスト設定・テスト・テスト結果画面） 振る舞い仕様書

## 1. 機能概要

フォルダの単語をカードで1枚ずつ出題し、ユーザーが正解・不正解を自己採点して、最後まで答えたら成績を保存して結果を表示する。
テスト設定画面（`/test-settings/<フォルダの id>`）→ テスト画面（`/test/<フォルダの id>`）→ テスト結果画面（`/flashcard-result`）の3画面で1つの流れになるため、1つの仕様書にまとめる。

対象の概要設計書は `docs/high_level_design/presentation/flashcard_mode/high_flashcard_mode_page.md`（根拠欄の `概要 §<見出し>`）。
成績の保存の結果は `docs/detailed_design/online_offline/flashcard_result_repository.md`（FRS-C）で、テスト設定画面が使う単語の一覧の読み込みは `docs/detailed_design/presentation/word/word_list_page.md`（WLS-V）で定める。

ログイン中のユーザーは id が `u1` のユーザー、フォルダは id が `F`、名前が「F」のフォルダとする。
単語「A」は表 `apple`・裏 `りんご`、単語「B」は表 `banana`・裏 `バナナ` で、「A」のほうが作成日時が古いものとする。
特に書かない限り、フォルダ「F」には単語「A」「B」があり、単語一覧画面（`/folder/F`）で「テストを開始」をタップしてテスト設定画面を開いたものとする。
条件の「シャッフルなしでテストを始めた」は、テスト設定画面で「シャッフル出題」をオフにして「テスト開始」をタップした状態を指す（1枚目は `apple`、2枚目は `banana`）。
条件の「めくった」は、カードをタップして回転が終わった状態を指す。

## 2. データ定義

### 2.1 FlashcardModeState

| 項目 | 型 | 説明 |
|------|----|------|
| isStarted | bool | テストを始めたか |
| isFinished | bool | 成績の保存まで終わったか |
| currentWord | Word? | 出題中の単語 |
| currentIndex | int | 出題中のカードの番号（0 始まり） |
| total | int | 出題数 |
| isFlipped | bool | 裏を表示しているか |
| correctCount | int | 正解数 |
| isSubmitting | bool | 成績を保存している途中か |
| errorMessage | String? | スナックバーに出す失敗の文言。なければ null |

### 2.2 入力ルール

該当なし（ユーザーが文字を入力する項目はない）。

## 7. 対象外

- **成績の保存の `NetworkFailure` / `AuthFailure`（画面）**: 成績の保存は端末内のデータベースだけを使い、リモートと通信しないため発生しない（FRS 7章）。ViewModel の文言の対応は FCM-V16〜V19 で定める
- **テスト設定画面の単語の一覧の読み込みの失敗の種類**: 読み込みは WLS-V で定める。この画面では「単語数の取得に失敗しました」の表示（FCM-S04）だけを定める
- **シャッフルの乱数の並び**: どの並びになるかは決めない（FCM-V03 で、全部が1回ずつ出ることだけを確かめる）
- **テスト中に追加・変更された単語を出題しないこと**: テスト画面は開いた時点の単語の一覧を受け取るため、テスト中の変更が入り込む経路がない
- **カードの回転のアニメーション、円グラフ・メッセージ・ボタンの色**: Widget テストで観測しないため、項目を作らない（色の区切りはメッセージの区切りと同じ。FCM-G01〜G08）
- **ボトムナビゲーションバー**: 3画面とも表示しないこと（FCM-S01, P01, G01）だけを確かめる
- **成績の保存中のローディング表示（原則-5）**: 保存は端末内のデータベースへの書き込みで瞬時に終わるため、「正解」「不正解」を無効にする（FCM-A05）だけにする
- **成績の保存の `NotFoundFailure` の後の答え直し**: フォルダが無いため答え直しても同じ失敗になる。`UnknownFailure` と同じ答え直しの動作（FCM-A08〜A09）で扱い、別の項目は作らない
