# ホーム画面（フォルダ一覧） 振る舞い仕様書

## 1. 機能概要

ログイン中のユーザーのフォルダを一覧で表示し、フォルダの作成・名前の変更・削除と、単語一覧画面への移動を行う画面（`/home`）。ログイン後に最初に表示し、ボトムナビゲーションバーの「ホーム」でも開く。

対象の概要設計書は `docs/high_level_design/presentation/home/high_home_page.md`（根拠欄の `概要 §<見出し>`）。
フォルダの保存・削除（配下の単語・成績の削除を含む）の結果は `docs/detailed_design/online_offline/folder_repository.md`（FLD）で定める。

ログイン中のユーザーは、特に書かない限り id が `u1` のユーザーとする。
フォルダ「A」「B」は、「A」のほうが作成日時が古いものとする（`getFolders` は作成日時の古い順に返す）。

## 2. データ定義

### 2.1 Folder

| 項目 | 型 | 説明 |
|------|----|------|
| id | String | フォルダの id |
| name | String | フォルダ名 |
| parentFolderId | String? | 親フォルダの id。この画面で作るフォルダは null |
| createdAt | DateTime | 作成日時 |
| updatedAt | DateTime | 更新日時 |

### 2.2 HomeState

| 項目 | 型 | 説明 |
|------|----|------|
| folders | AsyncValue<List<Folder>> | フォルダの一覧。読み込み中は `AsyncLoading` |

### 2.3 入力ルール

フォルダ名の幅は、半角の文字を1、全角の文字（ひらがな・カタカナ・漢字・ハングル・全角英数記号・全角空白）を2と数える。それ以外（半角英数記号・半角カナ・絵文字）は1と数える。

| ID | ルール | 守る層 | 境界値（有効 ／ 無効） | 根拠 | 確定度 |
|----|--------|--------|------------------------|------|--------|
| HOM-N01 | フォルダ名は、前後の空白（半角・全角）を除いて1文字以上 | 画面（作成ダイアログの「作成」・変更ダイアログの「保存」を無効にする）。ViewModel 以下には渡されない前提（テスト対象外） | 有効: `A` ／ ` A `（前後に半角空白） 無効: 空文字 ／ `   `（半角空白3文字） ／ `　`（全角空白1文字） | 概要 §フォルダ名のルール | 確定 |
| HOM-N02 | フォルダ名の幅は20以下（入力の段階で、前後の空白も幅に数える）。20を超える入力は受け付けず、入力前の内容のまま変わらない | 画面（入力欄）。ViewModel 以下には渡されない前提（テスト対象外） | 有効: `aaaaaaaaaaaaaaaaaaaa`（半角20文字） ／ `あいうえおかきくけこ`（全角10文字） ／ `あいうえおかきくけ12`（全角9文字＋半角2文字） ／ `😀` を20個 ／ `한국어한국어한국어한`（ハングル10文字） ／ `ＡＢＣＤＥＦＧＨＩＪ`（全角英字10文字） ／ `ｱｲｳｴｵｶｷｸｹｺｱｲｳｴｵｶｷｸｹｺ`（半角カナ20文字） 無効: `aaaaaaaaaaaaaaaaaaaaa`（半角21文字） ／ `あいうえおかきくけこさ`（全角11文字） ／ `あいうえおかきくけこ1`（全角10文字＋半角1文字） ／ `ＡＢＣＤＥＦＧＨＩＪＫ`（全角英字11文字） ／ `ｱｲｳｴｵｶｷｸｹｺｱｲｳｴｵｶｷｸｹｺｱ`（半角カナ21文字） ／ ` aaaaaaaaaaaaaaaaaaaa`（半角空白1文字＋半角20文字） | 概要 §フォルダ名のルール | 確定 |

- 加工の順序: 入力の段階で HOM-N02 を判定し、確定のボタンを押したときに前後の空白を除いてから保存に使う。HOM-N01 の判定も、前後の空白を除いた内容で行う

## 7. 対象外

- **`NetworkFailure` / `AuthFailure`（全操作）**: フォルダの読み取り・作成・変更・削除は端末内のデータベースだけを使い、リモートと通信しないため発生しない（FLD 7章、概要 §操作が失敗したとき）
- **初期読み込み・再読み込みの `NotFoundFailure`**: 一覧の取得で対象の不在は起きない（FLD 7章）
- **作成の `NotFoundFailure`**: この画面は親フォルダを指定せず（parentFolderId null）に作るため、削除済みの親フォルダによる `NotFoundFailure`（FLD-C07）は起きない
- **サブフォルダの作成・表示**: この画面では親フォルダを指定した作成・入れ子の表示を行わない
- **他のユーザーのフォルダを表示しないこと（原則-9）**: Repository の契約（FLD-R02）で検証する。画面では userId `u1` で呼ぶこと（HOM-V02）だけを確かめる
- **ボトムナビゲーションバー**: `docs/detailed_design/presentation/shell/shell_page.md`（SHL）で定める
- **ログイン後に最初にこの画面を表示すること・ボトムナビの「ホーム」で開くこと**: 画面への入り方は、移動する側の仕様書で定める（ログインの LGN-L04・スプラッシュの SPL-T02・ボトムナビの SHL-G18）
- **ダイアログのボタンの色（「削除」が赤）・アイコンの絵柄**: Widget テストで色・絵柄を観測しないため、項目を作らない
