## 状態の保存先と書き込み

- 状態は `accounts/{uid}.subscription` に置く（データ構造は `requirements.md` §8）
- **書き込むのはサーバーだけ。** 購入後、Cloud Functions がストアのレシート（または RevenueCat の Webhook）を検証してから書く。クライアントからは書き込まない（セキュリティルールで禁止済み）
- 更新は `set(..., { merge: true })` で `subscription` だけを書き、他のフィールド（開発者フラグ・同意）を壊さない
- 更新・解約・期限切れ・返金はストアからの通知（App Store Server Notifications / Google Play RTDN）を受けて反映する: 方式は TODO（要決定）

## プレミアムかどうかの判定

- `subscription` が無い → 無料
- `plan == 'premium'` かつ `status == 'active'` かつ `expiresAt` が現在より後 → プレミアム
- それ以外 → 無料
- 判定の時刻を端末時刻にするかサーバー時刻にするか: TODO（要決定）
