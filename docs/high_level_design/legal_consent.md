## 目的

ユーザーが利用規約とプライバシーポリシーに同意したことを、いつ・どの版に同意したかが分かる形で記録する。
規約を改訂したときは、新しい版への同意をもらう。

## 同意のタイミング

1. **新規登録時:** 登録の前に両方の文書を示し、同意してもらう。同意しないと登録できない
2. **改訂時:** ログイン中・起動時に、`app_config/legal` の現行版数と `accounts/{uid}.consents` の同意済み版数を比べ、違えば再同意を求める
- 利用規約とプライバシーポリシーを1つの画面でまとめて同意させるか、別々にするか: TODO（要決定）

## 同意の記録

- ユーザーが「同意する」を押すと、アプリが Cloud Functions（callable、例: `acceptLegal`）を呼ぶ
- Functions が呼び出したユーザーの uid（`request.auth.uid`）で `accounts/{uid}.consents` に、同意した版数とサーバー時刻（`agreedAt`）を書く
  - 端末時刻ではなくサーバー時刻にするのは、証跡として改ざんできないようにするため
  - `set(..., { merge: true })` で `consents` だけを書き、他のフィールドを壊さない
- クライアントは `accounts` に書き込まない（セキュリティルールで禁止済み）
- 新規登録時は、登録完了（uid の発行）後に記録する。登録画面で押した同意を、登録完了後に送る流れ: TODO（要決定）
