# 単語テスト（テスト設定・テスト・テスト結果画面） 概要設計書

> 2026-11-16 に、その時点のコードの動作から起こした概要設計書（ユーザー未レビュー）。
> テスト設定画面・テスト画面・テスト結果画面は1つの流れなので、この1つの概要設計書で定める。

## 目的

- フォルダの単語を、カード（表: 単語、裏: 意味）で1枚ずつ出題する
- ユーザーが裏を見て、正解・不正解を自分で選ぶ（自己採点）
- 最後まで答えたら、正解数と出題数を成績として保存し、結果を表示する

## 流れ

1. 単語一覧画面のテストの開始ボタンで、テスト設定画面を開く
2. 出題の順番（シャッフルするか）を選んで「テスト開始」を押下する
3. テスト画面で、カードを1枚ずつ答える
4. 最後のカードを答えたら成績を保存し、テスト結果画面を表示する

## テスト設定画面

### 画面への入り方

- 単語一覧画面のテストの開始ボタンを押下して開く（`/test-settings/<フォルダの id>`）
- ボトムナビゲーションバーは表示しない。AppBar の戻るボタンで単語一覧画面に戻る

### 画面構成

- AppBar には「テスト設定」と表示する
- 上から次の順に置く
  1. フォルダ名
  2. 単語数。フォルダの単語の数を「単語数: <数>枚」と表示する。読み込み中は「単語数を読み込み中...」、読み込みに失敗したら「単語数の取得に失敗しました」と表示する
  3. 区切り線
  4. 「シャッフル出題」のスイッチ（補足「オフにすると登録順に出題されます」）。開いた時点ではオン
  5. 画面の下端に「テスト開始」ボタン（再生のアイコン付き）
- 単語数が0のときは、「テスト開始」の下に赤字で「単語が1枚以上必要です」と表示する

### 「テスト開始」を押せる条件

| 状態 | 「テスト開始」 |
|-----|-------------|
| 単語が1枚以上ある | 押せる |
| 単語が0枚 | 押せない |
| 単語数の読み込み中 | 押せない |
| 単語数の読み込みに失敗した | 押せない |

### 出題の順番

| シャッフル出題 | 出題の順番 |
|--------------|----------|
| オン | フォルダの単語をランダムに並べ替えた順 |
| オフ | 登録順（作成日時の古い順。単語一覧画面と同じ順） |

- 出題する単語は、「テスト開始」を押下した時点のフォルダの単語すべて。テストの途中で単語が追加・変更されても、出題には反映しない

## テスト画面

### 画面への入り方

- テスト設定画面の「テスト開始」を押下して開く（`/test/<フォルダの id>`）
- AppBar・ボトムナビゲーションバーは表示しない

### 画面構成

- 上端の左に、何枚目かを「<何枚目> / <出題数>」で表示する（1枚目は「1 / <出題数>」）。右に、テストをやめる「×」のアイコンを置く
- その下に、進み具合のバー（<何枚目> ÷ <出題数> の長さ）を置く
- 中央に、カードを大きく表示する
  - 表を表示しているとき: ラベル「表」、その下に「タップして裏面を確認」（タップのアイコン付き。薄い色）、単語の表
  - 裏を表示しているとき: ラベル「裏」、単語の裏（「タップして裏面を確認」は表示しない）
  - 長い単語はカードの中でスクロールできる
- 下端に、「不正解」ボタン（×のアイコン。赤）と「正解」ボタン（チェックのアイコン。緑）を左右に並べる。そのカードを1回以上めくった後にだけ表示する

### カードをめくる

- 各カードは、表を表示した状態で出す
- カードを押下すると、カードが回転して裏を表示する。もう一度押下すると表に戻る（何度でもめくれる）
- 回転している間にもう一度押下しても、受け付けない
- 回転している間に「正解」「不正解」を押下したときは、受け付ける（判定はカードの面と関係ないため。ユーザー決定 2026-11-16）

### 自己採点

| 操作 | 処理 |
|-----|------|
| 最後のカード以外で「正解」を押下 | 正解数を1増やし、次のカードを表の状態で表示する。「正解」「不正解」は隠す |
| 最後のカード以外で「不正解」を押下 | 正解数は増やさず、次のカードを表の状態で表示する。「正解」「不正解」は隠す |
| 最後のカードで「正解」「不正解」を押下 | 成績（フォルダ・出題数・正解数・日時）を保存する。保存の間は「正解」「不正解」を表示しない（カードをめくると表示されるが、押せない）。保存に成功したら、テスト結果画面へ移動する（テスト画面は履歴に残さない） |

### 成績の保存に失敗したとき

- テスト画面のまま、スナックバーで失敗の理由を表示する
  - フォルダが見つからない（テスト中に他の端末でフォルダが削除された等）: 「データが見つかりません」
  - その他のエラー: 「エラーが発生しました: <エラーの内容>」
- 最後のカードのまま、もう一度答え直せる（カードをめくると「正解」「不正解」を再び表示する）。正解数は、失敗した回答を数えない
- 成績の保存は端末内のデータベースに書き込むだけなので、通信エラー・認証エラーは起きない（`online_offline.md`）

### テストをやめる

どちらの方法でやめても、成績は保存しない。再開の機能はない（最初からやり直す）。

- 最後のカードを答えて成績を保存している途中は、「×」・戻る操作を受け付けない。保存が終わったらテスト結果画面へ移る（ユーザー決定 2026-11-16。途中でやめても保存が終わると成績が残り、「成績は保存しない」と両立しないため）

#### 「×」を押下したとき

1. タイトル「テストを途中終了しますか？」
2. 本文「テストを途中終了すると成績には含まれません。」
3. 「いいえ」ボタン、「はい」ボタン

| 操作 | 処理 |
|-----|------|
| 「はい」を押下 | ホーム画面（`/home`）へ移動する |
| 「いいえ」を押下 | ダイアログを閉じて、テストを続ける（同じカードのまま） |
| ダイアログの外側を押下・戻る操作 | 「いいえ」と同じ |

#### 戻る操作をしたとき

1. タイトル「テストを中断しますか？」
2. 本文「途中の結果は保存されません。」
3. 「続ける」ボタン、「中断する」ボタン

| 操作 | 処理 |
|-----|------|
| 「中断する」を押下 | テスト設定画面に戻る |
| 「続ける」を押下 | ダイアログを閉じて、テストを続ける（同じカードのまま） |
| ダイアログの外側を押下・戻る操作 | 「続ける」と同じ |

## テスト結果画面

### 画面への入り方

- テスト画面で最後のカードを答え、成績の保存に成功すると表示する（`/flashcard-result`）
- AppBar・ボトムナビゲーションバーは表示しない

### 画面構成

上から次の順に置く。

1. 正答率の円グラフ（正答率の分だけ色を付けた輪）と、中央に正答率「<正答率>%」（正解数 ÷ 出題数 × 100 を四捨五入した整数）
2. 正答率に応じたメッセージ
3. 「<正解数> / <出題数> 問正解」
4. 「正解」の行（チェックのアイコン。右端に正解数）。緑
5. 「不正解」の行（×のアイコン。右端に 出題数 − 正解数）。赤
6. 画面の下端に「ホームに戻る」ボタン（家のアイコン付き）

| 正答率 | メッセージ | 円グラフ・正答率の色 |
|-------|----------|------------------|
| 90% 以上 | 「素晴らしい！」 | 緑 |
| 70% 以上 90% 未満 | 「よくできました！」 | 青 |
| 50% 以上 70% 未満 | 「もう少し！」 | オレンジ |
| 50% 未満 | 「もっと練習しましょう」 | 赤 |

- 正答率の区切りは、四捨五入する前の値で判定する

### 画面遷移

| 操作 | 遷移先 |
|-----|-------|
| 「ホームに戻る」を押下 | ホーム画面（`/home`） |
| 戻る操作 | テスト設定画面（テスト画面は履歴に残していないため） |

## 画面遷移（まとめ）

| 画面 | 操作 | 遷移先 |
|-----|-----|-------|
| テスト設定画面 | 「テスト開始」を押下 | テスト画面（`/test/<フォルダの id>`） |
| テスト設定画面 | 戻る | 単語一覧画面（`/folder/<フォルダの id>`） |
| テスト画面 | 最後のカードを答え、保存に成功 | テスト結果画面（`/flashcard-result`） |
| テスト画面 | 「×」→「はい」 | ホーム画面（`/home`） |
| テスト画面 | 戻る操作 →「中断する」 | テスト設定画面 |
| テスト結果画面 | 「ホームに戻る」を押下 | ホーム画面（`/home`） |
