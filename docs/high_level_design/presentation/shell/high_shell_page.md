# ボトムナビゲーション（シェル） 概要設計書

> 2026-11-16 に、その時点のコードの動作から起こした概要設計書（ユーザー未レビュー）。
> 「テスト」タブ（サンプル画面）を開発者だけに表示する条件は、`presentation/sample/high_sample_page.md` §表示条件で定める（詳細設計は `docs/detailed_design/presentation/shell/shell_page.md`）。

## 目的

ログイン後の主な画面を、画面の下のタブで切り替えられるようにする。

## タブ

左から次の順に並べる。

| タブ | アイコン（選んでいないとき ／ 選んでいるとき） | 画面 |
|-----|------------------------------------------|-----|
| ホーム | 家の線のアイコン ／ 塗りつぶしのアイコン | ホーム画面（`/home`） |
| 成績 | グラフの線のアイコン ／ 塗りつぶしのアイコン | 成績表画面（`/results`） |
| テスト | フラスコの線のアイコン ／ 塗りつぶしのアイコン | サンプル画面（`/sample`）。開発者のときだけ表示する |
| 設定 | 歯車の線のアイコン ／ 塗りつぶしのアイコン | 設定画面（`/settings`） |

- タブを押下すると、そのタブの画面へ移動する。それまでの画面の履歴は残さない（タブの画面で戻る操作をしても、前のタブには戻らない）
- 今開いている画面のタブを、選んでいる状態で表示する

| 開いている画面 | 選んでいる状態のタブ |
|-------------|------------------|
| ホーム画面（`/home`） | ホーム |
| 単語一覧画面（`/folder/<フォルダの id>`） | ホーム（ホーム画面から開く画面のため） |
| 成績表画面（`/results`） | 成績 |
| サンプル画面（`/sample`） | テスト |
| 設定画面（`/settings`） | 設定 |

## 表示する画面

ボトムナビゲーションバーは、次の画面にだけ表示する。

| 画面 | 表示 |
|-----|-----|
| ホーム画面・単語一覧画面・成績表画面・サンプル画面・設定画面 | 表示する |
| スプラッシュ・ログイン・新規登録・パスワード再設定・確認待ちの各画面 | 表示しない（ログイン前の画面のため） |
| アカウント情報画面・単語追加画面・単語編集画面 | 表示しない（AppBar の戻るボタンで元の画面に戻る画面のため） |
| テスト設定画面・テスト画面・テスト結果画面 | 表示しない（テストの流れの途中でタブに移らないようにするため） |
