# スプラッシュ画面 概要設計書

> 2026-11-16 に、その時点のコードの動作から起こした概要設計書（ユーザー未レビュー）。

## 目的

- アプリの起動時にロゴを表示する
- 起動直後に必要な確認（ログイン状態・退会処理の途中かどうか・強制ログアウトの記録）が終わるまで待ち、移動先を決める

## 画面への入り方

- アプリを起動すると最初に表示する（`/`）
- ボトムナビゲーションバー・AppBar は表示しない

## 画面構成

- 背景は紺色（`#15203B`）にする
- 画面の中央に、アプリアイコンの絵（ロゴ）を幅 256 で表示する
- 文言・ボタンは置かない

## 移動の条件

次の4つがすべてそろったときに、移動先へ移動する。どれか1つでもそろっていなければ、スプラッシュ画面のまま待つ。

1. 表示してから2秒が経った（ロゴを見せるための最低の表示時間）
2. ログイン状態の読み込みが終わった
3. 退会処理の記録の確認が終わった（途中で止まった退会処理があれば、移動先で再開ダイアログを出すため。`high_settings_page.md` §途中で止まった場合）
4. 強制ログアウトの記録の読み込みが終わった（`high_settings_page.md` §他の端末での退会）

- 2〜4 は、表示した直後から裏で並行して進める。2秒より先に終わっても、2秒経つまでは移動しない
- 2秒経った後に 2〜4 が終わったら、その時点で移動する
- 強制ログアウトの記録の読み込みに失敗したときは、記録が無いものとして読み込みを終える（起動を止めない）

## 移動先

| 状態 | 移動先 |
|-----|-------|
| ログインしていない | ログイン画面（`/login`） |
| ログイン状態の読み込みが失敗した | ログイン画面（`/login`） |
| ログイン中の uid が、強制ログアウトの記録の uid と同じ | ログイン画面（`/login`）。強制ログアウトした uid は、ログインしていないものとして扱う |
| 上のどれでもない（ログイン中） | ホーム画面（`/home`）。メールアドレスが未確認なら、ルーターが確認待ち画面（`/verify-email`）へ移す（`email_verification.md`） |

- 移動は履歴を残さない（移動先で戻る操作をしても、スプラッシュ画面には戻らない）
