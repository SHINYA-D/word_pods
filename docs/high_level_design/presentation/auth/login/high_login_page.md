# ログイン画面 概要設計書

> 2026-11-16 に、その時点のコードの動作から起こした概要設計書（ユーザー未レビュー）。

## 目的

- 登録済みのユーザーが、メールアドレスとパスワードでログインできるようにする
- パスワードを忘れたユーザー・まだ登録していないユーザーを、それぞれの画面へ案内する

## 画面への入り方

- ログインしていない状態でアプリを起動したとき、スプラッシュ画面から移動する（`/login`）
- ログアウト・退会・強制ログアウトの後に移動する
- ボトムナビゲーションバー・AppBar は表示しない

## 画面構成

- アプリのブランドの配色（紺の背景）で表示する。背景が紺なので、ステータスバーの文字は白にする
- 上から次の順に置く
  1. ロゴ（スプラッシュ画面と同じアプリアイコンの絵。高さ 160）
  2. アプリ名「WordPods」（中央寄せ・太字）
  3. 「メールアドレス」の入力欄（左にメールのアイコン）
  4. 「パスワード」の入力欄（左に鍵のアイコン。入力した文字は伏せ字。右端に、伏せ字と表示を切り替える目のアイコン）
  5. 「パスワードを忘れた方」のリンク（右寄せ・下線付き）
  6. 「ログイン」ボタン
  7. 「アカウントをお持ちでない方」の文言と、「新規登録」のリンク（下線付き）を横に並べる
- Google でログインするボタンは、一時的に表示しない（App Store 審査 Guideline 4.8。第三者のログインを置くには Sign in with Apple も必要なため。Sign in with Apple と同時に戻す）
- 画面が小さい端末・キーボードを表示しているときは、縦にスクロールできる

## 入力のチェック

「ログイン」を押下したときに確かめる。満たさない入力欄の下に赤字で表示し、ログインの処理は始めない。

| 入力欄 | 条件 | 表示 |
|-------|-----|------|
| メールアドレス | 空 | 「メールアドレスを入力してください」 |
| パスワード | 空 | 「パスワードを入力してください」 |

- メールアドレスは、前後の空白を除いてからログインに使う。パスワードは入力したまま使う
- メールアドレスの形式・パスワードの長さは、この画面では確かめない（Firebase Authentication の判定に任せる）
- メールアドレスに空白（半角・全角）だけを入力したときは、空と同じに扱い、「メールアドレスを入力してください」を表示してログインしない（ユーザー決定 2026-11-16。共通原則-8）

## ログインの処理

- 「ログイン」を押下すると、ログインの処理を始める
- 処理中は「ログイン」ボタンを押せないようにし、ボタンの文字の代わりにローディングを表示する
- ログインに成功したら、初回の同期（Firestore から端末への取得）を行う。同期の間は画面を移動しない（`online_offline.md`）。同期に失敗してもログインは成功として扱う
- 成功したら、ホーム画面（`/home`）へ移動する。メールアドレスが未確認なら、ルーターが確認待ち画面（`/verify-email`）へ移す（`email_verification.md`）

## ログインに失敗したとき

ログイン画面のまま、スナックバーで失敗の理由を表示する。入力した内容はそのまま残し、もう一度「ログイン」を押せるようにする。

| 失敗の種類 | スナックバーの文言 |
|-----------|-----------------|
| 通信エラー | 「通信エラーが発生しました」 |
| メールアドレス・パスワードの誤り（ユーザーがいない・パスワードが違う） | 「メールアドレスまたはパスワードが正しくありません」 |
| アカウントが見つからない | 「アカウントが見つかりません」 |
| その他のエラー | 「エラーが発生しました: <エラーの内容>」 |

- ログイン前の画面なので、通信エラーでも通信エラーダイアログの表示・強制ログアウトは行わない（共通原則-11 はログイン中の操作に当てはめる）
- 続けて失敗したときは、そのたびにスナックバーを表示する

## 退会が完了してこの画面に来たとき

退会処理の成功でこの画面に移動したときは、退会の完了ダイアログを表示する（`presentation/settings/high_settings_page.md` §完了ダイアログ）。

## 画面遷移

| 操作 | 遷移先 |
|-----|-------|
| 「パスワードを忘れた方」を押下 | パスワード再設定画面（`/password-reset`）。戻るとログイン画面に戻る |
| 「新規登録」を押下 | 新規登録画面（`/sign-up`）。戻るとログイン画面に戻る |
| ログインに成功 | ホーム画面（`/home`）。メールアドレスが未確認なら確認待ち画面（`/verify-email`） |
