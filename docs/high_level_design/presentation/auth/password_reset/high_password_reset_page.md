# パスワード再設定画面 概要設計書

> 2026-11-16 に、その時点のコードの動作から起こした概要設計書（ユーザー未レビュー）。

## 目的

パスワードを忘れたユーザーが、登録したメールアドレスに届くリンクから新しいパスワードを設定できるようにする。
ログイン中のユーザーがパスワードを変えるときも、ログアウトしてからこの画面を使う（`presentation/account/high_account_page.md` §パスワード変更）。ログイン中にこの画面を開く経路はない。

## 画面への入り方

- ログイン画面の「パスワードを忘れた方」を押下して開く（`/password-reset`）
- ボトムナビゲーションバーは表示しない。AppBar の戻るボタンでログイン画面に戻る

## 画面構成

- AppBar には「パスワードリセット」と表示する
- 上から次の順に置く
  1. 説明「登録済みのメールアドレスにパスワードリセット用のリンクを送信します。」
  2. 「メールアドレス」の入力欄（左にメールのアイコン）
  3. 「送信する」ボタン

## 入力のチェック

「送信する」を押下したときに確かめる。

| 入力欄 | 条件 | 表示 |
|-------|-----|------|
| メールアドレス | 空 | 入力欄の下に赤字で「メールアドレスを入力してください」。送信しない |

- メールアドレスは、前後の空白を除いてから送信に使う
- メールアドレスの形式は、この画面では確かめない（Firebase Authentication の判定に任せる）

## 送信の処理

- 処理中は「送信する」ボタンを押せないようにし、ボタンの文字の代わりにローディングを表示する
- 送信に成功したら、スナックバーに「パスワードリセットメールを送信しました」と表示し、ログイン画面に戻る

## 送信に失敗したとき

この画面のまま、スナックバーで失敗の理由を表示する。入力したメールアドレスは残し、もう一度送信できるようにする。

| 失敗の種類 | スナックバーの文言 |
|-----------|-----------------|
| 通信エラー | 「通信エラーが発生しました」 |
| メールアドレスのユーザーがいない | 「メールアドレスが見つかりません」 |
| アカウントが見つからない | 「アカウントが見つかりません」 |
| その他のエラー | 「エラーが発生しました: <エラーの内容>」 |

- ログイン前の画面なので、通信エラーでも通信エラーダイアログの表示・強制ログアウトは行わない
- 送信の処理中でも戻れる。送信は取り消さず、戻った後に送信が成功したら、ログイン画面でスナックバー「パスワードリセットメールを送信しました」を表示する（ユーザー決定 2026-11-16）

## 空白だけの入力

メールアドレスに空白（半角・全角）だけを入力したときは、空と同じに扱い、「メールアドレスを入力してください」を表示して送信しない（ユーザー決定 2026-11-16。共通原則-8）。

## 画面遷移

| 操作 | 遷移先 |
|-----|-------|
| 戻る（AppBar の戻るボタン・戻る操作） | ログイン画面（`/login`） |
| 送信に成功 | ログイン画面（`/login`）。スナックバーを表示する |
