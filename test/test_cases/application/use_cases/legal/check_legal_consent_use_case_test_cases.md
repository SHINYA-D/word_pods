## 検証の範囲（補足）

- LGL-K17：Fake の LegalRepository からは「項目の一部が欠けている」を作れないため、入力は K14（`Left(NotFoundFailure)`）と同じになる。項目が欠けたときに `NotFoundFailure` を返すことは Repository 実装側（LGL-R03〜R07 など）で確かめている。このテストでは、判定結果の config の4項目すべてが既定値になることを確かめる
